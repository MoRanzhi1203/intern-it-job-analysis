# 技能抽取人工验证 · 缺失数据说明

按补全任务 §1.2，本轮技能抽取人工验证**不计算 Precision / Recall / F1，也不计算 Cohen's Kappa**，
原因是缺少真实人工金标准。以下说明缺少的具体文件与字段。

## 1. 已存在的文件（不足以构成金标准）

| 文件 | 现状 |
| --- | --- |
| `data/interim/skill_annotation_sample.xlsx`（工作表 `01_标注表`） | 249 行 × 11 列，人工填写列**全部为空** |
| `docs/skill_annotation_guideline.md` | 标注规范（抽样方案、字段字典、判定规则），非标注结果 |
| `data/features/job_skill_membership.parquet` | 规则/词典自动抽取结果，只能作为被评价对象，不能作为金标准 |

## 2. 缺少的具体字段（`01_标注表` 现有 11 列中）

| 应有内容 | 现状 |
| --- | --- |
| 人工确认技能 | 字段 `人工确认技能` 存在但 **0 / 249 非空** |
| 是否可判定 | 字段 `是否可判定` 存在但 **0 / 249 非空** |
| 标注员 A 的独立标注 | **字段不存在** |
| 标注员 B 的独立标注 | **字段不存在** |
| 双人分歧记录 | **字段不存在** |
| 裁决结果 / gold label | **字段不存在** |

现有字段：`intern_id`、`公司名称`、`岗位大类`、`岗位细分类`、`要求段原文（节选）`、
`全文兜底原文（节选）`、`规则抽取_要求段统计范围`、`规则抽取_扩展统计范围`、`人工确认技能`、
`是否可判定`、`备注`。

## 3. 已排除的替代来源

- 全库按文件名词根 `annot` / `标注` / `kappa` / `gold` / `裁决` / `人工` 检索，除上述样本表与规范文档外，
  **未发现任何其他技能人工标注文件**。
- `data/interim/skill_annotation_sample.xlsx` 的其余工作表（`02_分层构成`、`03_抽样说明`）为抽样构成与抽样说明，
  不含岗位级人工判定。

## 4. 结论

- **不存在**两位标注员的独立原始标注，因此无法计算 observed agreement 与 Cohen's Kappa；
- **不存在**裁决后的 gold label（`人工确认技能` 全空），因此无法以人工结果为金标准计算 TP / FP / FN 与 P / R / F1；
- 按提示词要求，**不以规则抽取结果、模型输出或大语言模型生成结果代替金标准**，也不依据论文结论反推指标；
- 因此本轮不生成 `outputs/deliverables/tables/table_6_skill_extraction_validation.csv`。

## 5. 解锁条件

在 `data/interim/skill_annotation_sample.xlsx` 的 `01_标注表` 中完成 249 行的
`人工确认技能` 与 `是否可判定` 两列填写（如要计算一致性，另需补入两位标注员的独立标注列），
即可按 `docs/skill_annotation_guideline.md` 的评价标准生成技能抽取验证结果。
