## 3. 两套签名

- 核心业务签名字段（18 个）：岗位标题、薪资信息、工作城市、学历要求、每周到岗要求、实习时长要求、岗位标签、岗位描述、简历语言要求、工作地址、公司名称、公司简介、公司标签、所属行业、公司性质、公司规模、公司所在地、公司认证标签；
- 完整页面签名额外字段：发布时间、投递截止日期、岗位头图链接；
- 签名实现：归一化（去空值/排序/去空白）→ 稳定 JSON → SHA256，禁止使用内存 hash；
- 排除在核心签名之外的字段：发布时间、投递截止日期、岗位头图链接、岗位大类、岗位细分类、搜索页码、数据创建时间、数据更新时间。

## 4. 版本压缩规则

- 排序字段：观测时间 → 数据创建时间 → 稳定原始顺序；
- 连续相同核心业务签名压缩为一个核心版本；完整页面版本同步压缩；
- `A → B → A` 保留为三个连续版本，禁止把版本 1 与版本 3 重新合并；
- 版本时间定义：版本首次/末次观测时间取自该版本内观测快照的时间极值；最终版本的下一版本开始时间与到下一版本间隔均为空，不填任何人为时间。
