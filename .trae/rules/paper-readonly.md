# 论文目录只读约束（强制）

## 受保护路径

以下两个目录及其**全部内容**为只读区（含 `.docx`、`.pdf` 等所有文件）：

- `course-design-1/docs/paper/`
- `course-design-2/docs/paper/`

## 强制规则

1. **禁止写入**：不得在这两个目录中新建、写入、覆写、追加任何文件。
2. **禁止修改**：不得编辑、替换、重命名、移动其中的任何文件。
3. **禁止删除**：不得删除目录或其内容。
4. **仅允许读取**：可读取内容用于分析、引用、核对与展示。

## 适用范围

上述限制对以下所有方式一律生效，包括但不限于：

- 文件编辑类工具（写文件、替换文本、删除文件）
- 终端/Shell 命令（PowerShell `.ps1`、`.bat`/`.cmd`、重定向 `>`、`Out-File`、`Set-Content`、`Remove-Item` 等）
- Python / Jupyter Notebook 脚本
- 任何构建、格式化、导出、批处理脚本
- Git 等版本控制操作

## 唯一例外

只有用户本人手动打开文件夹、使用 Word/PDF 阅读器手动编辑才允许写操作。若用户要求 Trae 修改这两个目录中的文件，应先提示该目录为只读保护区，并请用户手动完成编辑，不得代为写入。
